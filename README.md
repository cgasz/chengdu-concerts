# 🎵 成都演唱会工作台

成都市演唱会信息汇总工作台（个人自用）：手机和电脑同一套布局，支持 PWA「添加到主屏幕」后像 App 一样全屏打开。

## ✨ 功能

- 🎤 演唱会列表：演出卡片（艺人/日期/场馆/票价/开票状态/购票渠道/来源链接），支持按艺人、场馆、月份筛选
- 📅 演出日历：已官宣演出按日期时间轴展示，今日高亮
- ⏰ 开票倒计时：未开票演出倒计时，避免错过抢票
- 🏟️ 场馆速览：11 个成都演出场馆（地址/交通/代表演出）
- 🎪 音乐节专题：葫芦果音乐节等汇总
- ⭐ 艺人追踪：关注艺人置顶高亮（localStorage，无需登录）
- 🎫 购票渠道指南 + 💡 抢票攻略：官方渠道、实名制、防骗提示
- 📢 动态公告：官宣/开票/变动提示
- 🗂️ 历史演出回顾 + 🔍 数据来源说明

## 📂 目录结构

```
index.html            应用外壳（左侧固定侧边栏 + 右侧内容区）
css/style.css         全站统一样式（深炭 + 蓉城朱红配色）
js/app.js             路由与页面渲染
manifest.json          PWA 清单（可添加到主屏幕）
sw.js                 Service Worker（离线缓存）
icons/                 PWA 图标（192/512/苹果）
data/concerts.json     演出数据（19 场已核实，含来源链接）
data/venues.json       场馆数据（11 个）
data/announcements.json 公告数据（9 条）
data/guides.json       购票渠道与攻略
data/site.json         更新日期/核验方法/待核实线索
```

## 🔄 数据更新方法

1. 修改 `data/*.json` 中对应条目（结构见各文件）；
2. 更新 `data/site.json` 的 `updatedAt` 为当天日期；
3. 重新部署即可（Service Worker 对数据文件采用网络优先策略，刷新即生效）。

## 🚀 部署

- GitHub Pages：直接推送本目录到仓库根目录（已含 `.nojekyll`），或运行 `tools/deploy.js`（需 `GH_TOKEN` 环境变量，GitHub 个人访问令牌，`repo` 权限）。
- 本地预览：`node tools/serve.js chengdu-concerts` 后访问 http://127.0.0.1:8090

## ⚠️ 数据说明

所有演出数据均逐条联网核实并附来源链接，核验优先级：成都市文广旅局审批公示 > 票务平台官方页 > 成都官方媒体。演唱会信息变动频繁，以官方最新公告为准。
